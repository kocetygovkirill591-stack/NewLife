# Технический отчёт V0.3.4

## Реализовано
Система трудоустройства с четырьмя вакансиями. Игрок выбирает вакансию, проходит собеседование (30 игровых минут, 5 энергии), получает должность и может работать. Смена длится 8 игровых часов, доступна не чаще одного раза в игровой день, начинается с 06:00 до 12:00 и требует минимум 25 энергии. После смены начисляется зарплата выбранной вакансии.

## Сохранение
Добавлены поля work.job_id, work.shifts_completed, work.total_earned, work.last_shift_day. SAVE_VERSION=2. Старые сейвы версии 1 остаются читаемыми; отсутствующие поля получают значения по умолчанию.

## Ограничения
Пока нет NPC-собеседований, расписаний отдельных работодателей, налогов, расходов на жильё и автоматического увольнения. Приём после собеседования гарантирован — это первый игровой прототип трудоустройства.

## Проверки
Локально выполнены статические проверки структуры, связности экранов, сохранения новых полей, совместимости старого формата и целостности ZIP. Компиляция и запуск Godot 4.3 будут проверены отдельным GitHub Actions запуском после коммита. Физическое устройство не подключено.
