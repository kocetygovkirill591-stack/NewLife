# Новая Жизнь — Godot source mirror V0.3.4

V0.3.4 добавляет первый рабочий цикл трудоустройства: четыре вакансии, собеседование, восьмичасовую смену, выплату зарплаты, увольнение и сохранение карьерного прогресса.

GDScript хранится в gzip+base64 частями в `.github/source/v0.3.4/`; GitHub Actions склеивает части и восстанавливает обычный `scripts/main.gd` перед импортом проекта. Визуальные ресурсы остаются SVG.

Откройте `godot-project/project.godot` в Godot 4.3+. Целевая Android-архитектура — ARM64.

Сохранения V0.3.3 (SAVE_VERSION=1) читаются автоматически. При следующей записи они обновляются до SAVE_VERSION=2; новые поля работы получают безопасные значения по умолчанию.
